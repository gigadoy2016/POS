# Bua Ngoen Modern POS & Inventory Management System (ร้านบัวเงิน POS)

ระบบ Point of Sale (POS) และจัดการสต็อกสินค้ายุคใหม่ พัฒนาด้วย **Node.js + SQLite** 
ออกแบบมาเพื่อตอบโจทย์ **"กินสเปกต่ำมาก (RAM ~35MB), เร็วทันใจ, หน้าตาสวยโมเดิร์นระดับ Premium"** 
และถอดแบบฟังก์ชันมาจากระบบเดิม (`INVapp / CakePHP 1.1`) ครบถ้วน 100%

---

## 🌟 ฟังก์ชันหลัก

1. **🛒 หน้าขายหน้าร้าน (POS Terminal)**
   * **ยิงบาร์โค้ด / สแกนด่วน (F1):** พร้อมระบบเสียง Beep จำลองผ่าน Web Audio API
   * **ค้นหาแบบ Real-time:** ค้นหาชื่อสินค้า, รหัส, หมวดหมู่ ได้ทันทีจากสินค้ากว่า 3,500 รายการ
   * **เลือกตามหมวดหมู่ / ชนิดสินค้า:** แสดงหมวดหมู่ (ด้าย, ไหม, ซิป, กรรไกร ฯลฯ) พร้อมรูปสินค้า
   * **ระบบโปรโมชั่นอัตโนมัติ:** คำนวณราคาแพ็คเกจ / ส่วนลดตามจำนวนที่ซื้ออัตโนมัติ (เช่น 6 ชิ้น หรือ 1 โหล)
   * **ส่วนลดท้ายบิล (F3):** ใส่ส่วนลดเป็นบาทได้ทันที
   * **พักบิล & เรียกบิล (F2):** สลับรับลูกค้าท่านอื่นได้โดยไม่ต้องเคลียร์ตะกร้า
   * **คิดเงิน & คำนวณเงินทอน (Space):** มีปุ่มลัดเงินสดด่วน ฿50, ฿100, ฿500, ฿1000 และ Numpad สวยงาม
   * **พิมพ์ใบเสร็จ:** หน้าต่างตัวอย่างใบเสร็จ Slip Thermal 80mm พร้อมปุ่มสั่งพิมพ์ออกเครื่องพิมพ์ได้ทันที

2. **📦 จัดการคลังสินค้า & สต็อก (Safety Stock System)**
   * แสดงสินค้าทั้งหมด (3,537 รายการ)
   * ระบบแจ้งเตือน **Safety Stock Min/Max** (ตาม `inv_limitcheck` เดิม)
   * แก้ไขราคาทุน, ราคาขาย, จำนวนสต็อกคงเหลือ และจุดเตือนสต็อกได้ทันที

3. **🧾 ประวัติบิลย้อนหลัง**
   * ดูรายการบิลทั้งหมด ยอดขาย กำไร และสามารถกดดูรายการสินค้าหรือสั่งพิมพ์ใบเสร็จซ้ำได้

4. **📊 รายงานสรุปภาพรวม**
   * ยอดขายวันนี้, กำไรสุทธิวันนี้, จำนวนบิลวันนี้, จำนวนสินค้าใกล้หมดสต็อก

---

## ⚡ สเปกและการทำงาน
* **Memory Footprint:** กิน RAM เพียง **~35 - 50 MB**
* **Database:** SQLite `inv.db` (ขนาดเพียง 1.38 MB ไม่ต้องเปิด Background Service ให้หนักเครื่อง)
* **พอร์ตใช้งาน:** `http://localhost:3000`

---

## 🚀 วิธีเปิดใช้งาน

เปิดโฟลเดอร์นี้ใน Terminal / PowerShell:
```bash
# 1. รันระบบ POS
npm start
```
เปิดเบราว์เซอร์ไปที่: **http://localhost:3000**

*(กรณีต้องการซิงค์ข้อมูลใหม่ล่าสุดจาก MySQL Container เดิม ให้รัน `npm run sync`)*

## ⌨️ คีย์ลัดบนคีย์บอร์ด (Keyboard Shortcuts)
* **F1:** โฟกัสช่องยิงบาร์โค้ด
* **F2:** พักบิลปัจจุบัน
* **F3:** ใส่ส่วนลดท้ายบิล
* **SPACE (เว้นวรรค):** เปิดหน้าจอชำระเงิน
* **ESC:** ปิดหน้าต่าง Popup / Modal
