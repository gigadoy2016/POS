# Autonomous Execution & Full Permission Guidelines

- **Full Authority Granted**: The user has granted full permissions to execute tasks, write files, modify codebase, and run terminal commands autonomously.
- **Do Not Halt for Simple Confirmations**: Do not ask "Should I proceed?" or use multiple-choice confirmation modals for ordinary tasks. Implement the solution directly and verify it.
- **Action-Oriented**: Proactively make necessary edits, run verification commands, and report the completed results.
- **Only Ask When Strictly Necessary**: Only pause to ask the user if there is critical ambiguity or an unrecoverable external blocker that cannot be resolved automatically.
